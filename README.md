# remarkable-utils

A collection of small utilities and other items for working with or customising my
reMarkable tablet.

## Contents

- `scripts/` — standalone utility scripts, installable by symlinking into a
  directory on `PATH`. See [`scripts/README.md`](scripts/README.md) for details
  and documentation of each script.
  - `text2png` - convert a text file to a syntax highlighted png to drop into a notebook.
